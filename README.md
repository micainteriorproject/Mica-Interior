# Mica Interior Project

Website landing page untuk **Mica Interior Project** — studio kitchen set custom.

## Fitur

- 6 koleksi dapur (Japandi, Modern, Industrial, Klasik, Tropis)
- Filter gaya
- Form estimasi harga per meter
- Pilih layout dapur
- Salin ringkasan pesanan & buka DM Instagram

## Hosting (GitHub Pages)

Repo ini sudah siap di-host sebagai **static site**.

1. Buka **Settings → Pages** di repo GitHub
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Simpan

Situs akan tersedia di:

`https://azismuslim9428-netizen.github.io/Mica-Interior/`
